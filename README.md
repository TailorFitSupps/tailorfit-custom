# tailorfit-custom

Custom builder script for Tailor Fit (`custom-supplement.js`). The live site pins this file by release tag.

## Impeccable

This repo includes a [project-scoped Impeccable](https://impeccable.style) install for Cursor (skills + hooks) and a non-blocking PR detector workflow.

`PRODUCT.md` and `DESIGN.md` are **not** generated here yet — they will come from WebOps / the brand guide. Do not run `/impeccable init` until those land.
